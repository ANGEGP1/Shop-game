# SuperMart Battle — image2 Pixel Asset Prompts

Use these prompts to generate small, consistent pixel-art assets for the MVP. Keep the camera top-down or three-quarter top-down, avoid 3D rendering, and export assets with transparent backgrounds when possible.

## Style Guide

- 2D pixel art, top-down supermarket game style.
- Bright and friendly classroom-project look.
- Similar visual feeling to classic farming or monster-catching RPG maps, but original assets only.
- No 3D, no realistic photo style, no weather effects.
- Use a limited color palette and thick readable silhouettes.

## Tileset Prompt

```text
Create an original 2D pixel-art supermarket floor tileset for a top-down browser game called SuperMart Battle. Include cream floor tiles, green aisle carpet, checkout path tiles, wall edge tiles, and small decorative signs. Style: cheerful pixel art, 32x32 tiles, transparent background, no 3D, no weather, no text labels.
```

## Store Zone Prompt

```text
Create original 2D pixel-art supermarket stall assets for a top-down multiplayer management game. Include small shop counters, colored player stall borders, price signs without readable text, and simple display areas. 32x32 pixel tile scale, transparent background, bright friendly colors, no 3D.
```

## Customer NPC Prompt

```text
Create a sprite sheet of original 2D pixel-art supermarket customer NPCs for a top-down game. Include 4 diverse customers, each with walking frames facing up, down, left, and right. Small readable sprites, 32x32 frame size, transparent background, cheerful style, no 3D.
```

## Product Icon Prompts

### Milk
```text
Create an original 2D pixel-art milk carton icon for a supermarket management game. 32x32 pixels, transparent background, readable silhouette, simple blue and white carton, no text.
```

### Bread
```text
Create an original 2D pixel-art bread loaf icon for a supermarket management game. 32x32 pixels, transparent background, warm brown colors, readable silhouette, no text.
```

### Juice
```text
Create an original 2D pixel-art juice bottle icon for a supermarket management game. 32x32 pixels, transparent background, orange liquid color, readable silhouette, no text.
```

## Shelf Prompt

```text
Create original 2D pixel-art supermarket shelf sprites for a top-down management game. Include three shelf fill levels: empty, half-stocked, and full-stocked. 32x32 or 64x32 pixel scale, transparent background, warm wooden shelf, clear product spaces, no 3D.
```

## Recommended MVP Asset Order

1. Customer NPC sprite sheet.
2. Product icons for Milk, Bread, and Juice.
3. Shelf sprites with empty, half, and full states.
4. Floor tileset.
5. Store stall borders in 8 player colors.
